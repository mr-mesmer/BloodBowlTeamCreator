# Dugout Roster Builder

Одностраничный конструктор ростеров Blood Bowl 2025 для пользовательского EuroBowl-пака. Работает локально в браузере, без аккаунта и сервера.

## Возможности

- 31 ростер BB2025, включая Bretonnians, Chaos Renegades, Slann и Khorne.
- Пользовательские тиры, бюджеты и позиционные лимиты.
- Два независимых бюджета: **Team Budget** и **Skill Gold**. Остаток одного не покрывает расходы из другого.
- Обычные игроки, Primary/Secondary навыки, Elite-надбавки и стаки двух Primary.
- 52 разрешённые звезды с проверкой лиг, спецправил, парных звёзд и лимита Veterans/Legend.
- Спонсоры, именитые тренеры, сайдлайн-стаф и разрешённые поощрения.
- Компактная сводка ошибок: лимиты позиций, число игроков, Big Guys, навыки и оба бюджета.
- Автосохранение текущего ростера в `localStorage`.
- Печать/PDF, экспорт JSON и TXT.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Проверки:

```bash
npm test
```

## Где менять правила

- `src/lib/rules.ts` — бюджеты тиров, цены навыков, звёздные доплаты, спонсоры, тренеры и поощрения.
- `src/lib/engine.ts` — стоимость и валидация ростера.
- `src/data/catalog.json` — команды, позиции, навыки и звёзды.
- `scripts/build_catalog.py` — воспроизводимая генерация каталога из исходных данных.

Интерфейс не содержит отдельной страницы правил: выбранные значения отображаются непосредственно в конструкторе и в печатной версии.

## Тесты

Vitest покрывает бюджеты всех тиров, независимое превышение каждого бюджета, контракты, Elite/Secondary/стаки, парные звёзды, доступность по лигам, позиционные лимиты и Big Guys.
